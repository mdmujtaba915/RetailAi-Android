## Fast setup

1. Create a new GitHub repository named `RetailAi-Android`.
2. Upload the contents of this folder (not the outer ZIP).
3. Push to the `main` branch.
4. Open GitHub -> Actions -> `Build RetailAI Android`.
5. After the workflow succeeds, download the APK/AAB from the workflow's Artifacts section.

This first build is an unsigned test build. Play Store production signing will be configured in the release phase.
